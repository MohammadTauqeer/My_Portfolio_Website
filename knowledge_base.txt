# Project Knowledge Base: My Portfolio

This document provides a summary of the core components and pages within the project, specifically covering `components/sections/` and `app/`.

## Application Structure (app/)

- **app/page.tsx**: The main entry point for the portfolio. It orchestrates the following sections:
  - `Scene`: Background/ambient scene.
  - `Hero`: Hero section with introductory content.
  - `AboutExperience`: Details about professional experience and background.
  - `PortfolioGrid`: A section displaying featured projects.
  - `Skills`: A showcase of technical skills.
  - `ProjectDiscovery`: An interactive section for exploring projects.
  - `Resume/CV`: A section for viewing and downloading the CV.
  - `ChatBot`: An interactive chatbot component.
  - `Footer`: Site footer.
- **app/layout.tsx**: The root layout wrapping all pages.
- **app/globals.css**: Global styling and Tailwind CSS configurations.

## Core Components (components/sections/)

- **Hero.tsx**: The main landing section with prominent calls to action and branding.
- **AboutExperience.tsx**: Handles the presentation of work history and personal biography.
- **PortfolioGrid.tsx**: A grid-based component for displaying project thumbnails and details.
- **ProjectDiscovery.tsx**: Interactive project explorer.
- **Skills.tsx**: Visual representation of technical expertise.
- **Scene.tsx**: Likely a 3D or background animation component (using Three.js/R3F if present).
- **ChatBot.tsx**: Interactive assistant component.
- **CustomCursor.tsx** & **CursorTrail.tsx**: Interactive cursor effects for enhanced UX.
- **index.ts**: Central export file for components.

## Key Data Sources
- **lib/data.ts**: Contains the core data for projects, skills, and experience.
- **lib/utils.ts**: Shared utility functions.
